Step 2

Download WeDo 2.0

Tap once. The WeDo 2.0 .apks package will download into the tablet's normal Downloads folder.

2 · DOWNLOAD WeDo 2.0
Important: Do not rename, unzip, convert, or modify the downloaded .apks file.
Download started ✓

When it finishes, open APK Installer by Braveheart. It should detect the WeDo file in Downloads.

Inside APK Installer:
  1. Select WeDo.2.0v1.10.259.apks .
  2. Tap Install.
  3. If Android asks for permission to install from this source, follow the Android permission screen and continue.

SmartHub not connecting?

Go to Settings → Apps → WeDo 2.0 → Permissions. Allow the permissions available on the tablet, especially Nearby devices and Location. Make sure Bluetooth and Location are on, then reopen WeDo.
